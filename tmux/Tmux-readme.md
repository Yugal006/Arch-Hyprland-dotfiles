# TMUX Developer Showcase Configuration

A modern, minimal, and dynamically themed tmux setup built for productivity, navigation speed, and plugin-driven workflow.

This configuration is designed around:

- Fast pane + window management
- Dynamic theming via Matugen (wallpaper-based colors)
- TPM plugin ecosystem
- Vi-style navigation inside tmux
- Developer-first workflow (Neovim + terminal integration friendly)

---

# 📌 Design Philosophy

This tmux setup follows a strict structure:

1. Prefix-first workflow (no Ctrl+B)
2. Vi-style pane interaction
3. Plugin-enhanced productivity (fzf, resurrect, TPM)
4. Dynamic UI theme from wallpaper (Matugen)
5. Minimal friction between tmux ↔ Neovim ↔ terminal

---

# ⌨️ Prefix Key

| Action | Key |
|------|-----|
| Prefix key | `Ctrl + Space` |

All tmux commands start from this prefix.

---

# 🪟 Window Management

| Action | Key |
|------|-----|
| Next window | Prefix + n |
| Previous window | Prefix + p |
| New window | Prefix + c |
| Close window | exit shell or Ctrl + d |

---

# 🧩 Pane Management

| Action | Key |
|------|-----|
| Split horizontal | Prefix + - |
| Split vertical | Prefix + \| |
| Navigate panes | Prefix + arrow keys (vi mode enabled) |
| Resize panes | Prefix + arrow keys (hold, terminal dependent) |

# 🎨 Theme System (Matugen Integration)

This setup uses Matugen to dynamically generate tmux colors based on wallpaper.

## Theme File

```

~/.config/tmux/generated.conf

````

## Behavior

- Wallpaper changes trigger Matugen regeneration
- tmux loads theme automatically:

```tmux
source-file ~/.config/tmux/generated.conf
````

## Theme Variables

- @thm_bg
    
- @thm_fg
    
- @thm_primary
    
- @thm_surface
    
- @thm_outline

# 🧠 Plugin System (TPM)

Managed via:

```
~/.tmux/plugins/tpm
```

---

## Installed Plugins

### 1. tmux-fzf

Fuzzy finder for:

- Sessions
    
- Windows
    
- Panes
    
- Commands
    

---

### 2. tmux-resurrect

Session persistence system:

- Save tmux sessions
    
- Restore after reboot
    
- Restore pane layouts + running programs
    

---

### 3. TPM (Tmux Plugin Manager)

Core plugin manager:

- Install plugins
    
- Update plugins
    
- Clean plugins
